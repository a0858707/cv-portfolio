Custom Rate Limiter & Webhook Gateway: Why We Outgrew RabbitMQ

During massive advertising campaigns with 20,000+ concurrent leads, standard message brokers like RabbitMQ choked on asymmetric downstream rate limits. CRM API v4 enforces a strict 7 req/sec quota, WhatsApp WABA APIs have dynamic burst limits, and accounting systems allow only 3 req/sec. RabbitMQ's backpressure caused queue stalls, head-of-line blocking, and catastrophic 429 lockouts.

n8n Webhook Ingestion The gateway intercepts raw webhooks emitted from n8n nodes, assigning priority flags (VIP sales leads vs bulk marketing drips).
Token-Bucket Pacing Maintains independent sliding-window token buckets per destination: 6.8 req/s for CRM API v4, 40 req/s for WABA, 5 req/s for Accounting & Billing APIs.
Zero-Loss Distribution Automatically retries transient network drops with jittered exponential backoff and archives dead letters with 1-click re-dispatch.
